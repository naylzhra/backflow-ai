# Backflow AI - Frontend

This is the frontend web application for Backflow AI, built using React, Vite, and Tailwind CSS v4.

## Getting Started

### Prerequisites

Make sure you have Node.js (v22 or higher) and npm/pnpm installed.

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The server will start (usually on http://localhost:8443 or similar, check terminal output).

### Build for Production

```bash
npm run build
```

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4 (using `@tailwindcss/vite` plugin)
- **Language**: TypeScript
